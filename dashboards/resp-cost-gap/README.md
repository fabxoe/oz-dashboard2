# 감염성 호흡기 질환 진료비 격차

## 목적
식약처 보건의료분석담당자가 소득 수준(빈부격차)에 따라, 그리고 기관 종별·권역에 따라 진료비가 얼마나 다른지 주기적으로 확인한다. 감염성 호흡기 질환(J00~J22)을 깊게 본다.

## 정의 (인터뷰 확정)
- **대상 질환**: 주상병(`claim.main_sick`)이 J00~J22인 명세서. 부상병은 포함하지 않는다.
- **소득 대리변수**: `patient.prem_quintile` (건강보험료 5분위). **5가 고소득**, 1이 저소득. 사업소득 등은 반영하지 못하는 한계를 화면에 주석으로 표시한다.
- **기관 종별**: `institution.cl_cd` (상급종합·종합병원 ~ 의원). 표시 이름은 `code_table`에서 가져온다.
- **권역/시도**: 기관 권역은 `institution.region_cd`, 환자 거주 시도는 `patient.sido_cd`(이름은 `sido_code`).
- **금액 지표**: 건당 총진료비 = `rvd_rpe_tamt_amt` (명세서 한 건). 평균과 중앙값을 함께 보여준다.
- **보정**: 먼저 단순 비교. 연령대(`patient.birth_yr` 기준)로만 층화한 값을 나란히 표시한다. 성별·중증도 표준화는 하지 않는다.
- **주기**: 월 단위 추이(`recu_fr_dd` 기준 월). 데이터는 사람이 갱신해 CSV를 교체한다.

## 지표
| 지표 | 정의 | 차트 |
|---|---|---|
| 건당 총진료비 (소득 5분위별) | 5분위별 평균/중앙값 | 막대 |
| 건당 총진료비 (기관 종별) | 종별 평균/중앙값 | 막대 |
| 건당 총진료비 (기관 권역, 환자 시도) | 권역/시도별 평균 | 표 또는 지도형 막대 |
| 소득 5분위 × 기관 종별 | 건당 총진료비 교차표 | 히트맵 |
| 월별 추이 | 위 지표의 월별 값, 전월 대비 | 선 |
| 연령대 층화 | 연령대별로 위 지표 재계산 | 막대(나란히) |
| 하위 질환 드릴다운 | J00~J22 안의 세부 상병별 건수·진료비 | 표 |

## 필터 / 나누어 볼 기준
- 기간(월), 소득 5분위, 기관 종별, 권역/시도, 연령대, 하위 상병

## 확인 필요 / 한계
- 기관 이름은 `institution`에 없고 `hospital_open`과 연결할 키도 없다. 기관은 종별·권역·ID 단위로만 본다.
- 소득 5분위는 환자 단위 값이다. 기관별 소득 구성은 환자와 연결해 계산한다.
- 표본 크기가 작은 칸(건수 부족)은 값을 숨기거나 표시한다. 기준 건수는 미정.

## 메모
- 인터뷰 1차 완료. 남은 질문: 최소 건수 기준, 코드 라벨 확인(`cl_cd`, `region_cd`), 보고 화면 우선순위.
